# 🚀 AI Ticket Platform 🎫🤖

> An intelligent AI-powered ticket management platform built using **React**, **Vite**, and **Tailwind CSS**.  
> Designed to simplify ticket creation, tracking, and management with a modern UI and scalable frontend architecture.

---

## ✨ Features

- 🎟️ **Create and Manage Tickets**
- 🤖 **AI-Assisted Ticket Workflow**
- 📊 **Modern Dashboard Interface**
- 🔍 **Ticket Status Tracking & Filtering**
- ⚡ **Lightning Fast Performance with Vite**
- 🎨 **Responsive UI using Tailwind CSS**
- 📱 **Mobile-Friendly Design**
- 🧭 **Client-Side Routing with React Router**
- ✨ **Beautiful Icons with Lucide React**

---

# 🛠️ Tech Stack

## 🎨 Frontend
- **React 19**
- **Vite**
- **Tailwind CSS**
- **React Router DOM**
- **Lucide React**

## ⚙️ Development Tools
- **ESLint**
- **PostCSS**
- **Autoprefixer**

# ⚙️ Installation

## 📥 Clone the Repository

```bash
git clone https://github.com/Harshavardhan0909/ai-ticket-platform.git
```

## 📂 Navigate to Project Directory

```bash
cd ai-ticket-platform
```

## 📦 Install Dependencies

```bash
npm install
```

---

# ▶️ Running the Project

## 🚀 Start Development Server

```bash
npm run dev
```

## 🏗️ Build for Production

```bash
npm run build
```

## 👀 Preview Production Build

```bash
npm run preview
```
