AI Ticket Platform 🎫🤖

An intelligent AI-powered ticket management platform built using React, Vite, and Tailwind CSS.
The platform is designed to streamline ticket creation, tracking, and management with a modern UI and scalable frontend architecture.

🚀 Features
🎟️ Create and manage support tickets
🤖 AI-assisted ticket handling workflow
📊 Clean and responsive dashboard UI
🔍 Ticket status tracking and filtering
⚡ Fast performance with Vite
🎨 Modern UI using Tailwind CSS
📱 Fully responsive design
🧭 Client-side routing with React Router
✨ Beautiful icons with Lucide React

⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/ai-ticket-platform.git

Move into the project directory:

cd ai-ticket-platform

Install dependencies:

npm install
▶️ Running the Project

Start the development server:

npm run dev

Build for production:

npm run build

Preview production build:

npm run preview
